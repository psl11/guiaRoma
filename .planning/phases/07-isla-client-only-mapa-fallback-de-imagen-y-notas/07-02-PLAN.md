## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OSM tile server → browser | External image tiles loaded at runtime over the network. Untrusted availability (not content — they are images); failure handled by the offline-banner heuristic, not a security control. |
| typed data → popup HTML string | `name`/`day` interpolated into `bindPopup(html)` originate from zod-validated `trip.yml`/monuments (trusted authoring), not user input. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03 | Tampering / Info Disclosure | popup `bindPopup(html)` interpolating `name`/`day` | accept | `name`/`day` come from zod-validated `trip.yml` (trusted authoring), identical trust model to the live site; not user input. No reflection of any user-controlled value. Leaflet popups take an HTML string by API (not a Vue template) — interpolating trusted strings is the only option and is safe by source. (07-RESEARCH.md ## Security Domain V5.) |
| T-07-04 | Denial of Service | OSM tiles unreachable | accept | By design: the verbatim `tilesErrored > 3 && tilesLoaded === 0` heuristic shows the offline banner + keeps markers; real offline tile caching is PWA/v2 (CLAUDE.md §9). Not a security failure. |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No installs. `leaflet@1.9.4` + `@types/leaflet@1.9.21` already in package.json (07-RESEARCH ## Package Legitimacy Audit — N/A). Do NOT add `import 'leaflet/dist/leaflet.css'` (already global). |

No HIGH-severity threats. ASVS L1: V5 satisfied (no user input reflected); V2/V3/V4/V6 N/A (static, no auth, no secrets).
