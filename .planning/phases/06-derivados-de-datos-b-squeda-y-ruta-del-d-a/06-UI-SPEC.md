# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **PARITY PHASE — NOT A NEW DESIGN.** Per CLAUDE.md Core Value, the 1.0 must be *exactly* like the live `index.html` (pixel + behavior parity). There is NO new visual design in Phase 6. Both surfaces this phase touches — the **search box + dropdown** and the **"ruta del día" button** — already have their full markup shells and CSS rendered verbatim in the codebase. This contract **detects and locks** the established design system; it does not invent tokens, spacing, type scales, or copy. Every value below is sourced from `app/assets/css/tokens.css`, `app/assets/css/base.css`, or `index.html` (the parity source of truth). The deliverable for the planner/executor is: **wire behavior into the existing shells, change zero CSS, render results with Vue `{{ }}` (never `v-html`).**

## Interaction Contract

> This is the load-bearing section for a parity phase. Behavior = the original 1:1 (D-03, D-04). No keyboard nav, no enriched rows, no shortcuts (all explicitly deferred — see CONTEXT §Deferred Ideas).

### Search box + dropdown (FEAT-03 / D-03)

| Aspect | Contract | Source |
|--------|----------|--------|
| Trigger | Typing in the `#search` input (`@input`). NO keyboard shortcut to focus (`/`, `⌘K` deferred). | D-04, `index.html:6447` |
| Open threshold | Dropdown opens only when trimmed query length **≥ 2** chars; `< 2` → close (`isOpen=false`). | `index.html:6449` |
| Max results | **8** (`.slice(0, 8)`). | `index.html:6450` |
| Result row markup | `<a href="#{slug}" class="search-result" :data-card="slug">{name}<div class="search-result-meta">{day}</div></a>` — VERBATIM shape (Pitfall 5). | `index.html:6453` |
| Empty state | `<div style="padding:.65rem 1rem;color:var(--ink-faint);font-style:italic">Sin resultados</div>` — inline style verbatim. | `index.html:6451` |
| Visibility mechanism | Toggle `.show` on `#search-results` (`.search-results.show { display:block }`). | `base.css:265` |
| Select a result (click) | `isOpen=false` → clear input (`query=''`) → `navigateToCard(slug, event)` (F5). NO direct hash jump. | `index.html:6459-6461` |
| Close on outside click | `document` click where `!target.closest('.search-wrap')` → close. Register in `onMounted`, clean up in `onUnmounted` (F5 listener precedent; register hooks SYNCHRONOUSLY before any `await`). | `index.html:6467-6469` |
| Render safety (LOCKED) | Results render via Vue **`{{ }}` interpolation only** (auto-escaped). **NEVER `v-html`.** The original used `innerHTML` with the data; F6 improves it by using templates. `name`/`day` come from MiniSearch `storeFields`. | RESEARCH §Security Domain (XSS / V5) |
| No keyboard navigation | No ↑/↓/enter/esc handling, no focus ring on rows, no active-descendant. (Deferred a11y improvement, NOT this phase.) | CONTEXT §Deferred |

### "Ruta del día" button (FEAT-09 / D-04)

| Aspect | Contract | Source |
|--------|----------|--------|
| Location | Appended INSIDE each day's `.day-stats` band (after the `v-for` of stats items). `margin-left:auto` pushes it right. | `index.html:6644`, `base.css:397` |
| Trigger | Plain external link — `<a target="_blank" rel="noopener">`. Click opens Google Maps. NO JS handler, NO `navigateToCard`. | `index.html:6635-6639` |

| Stops source | `day.cards` order (DATA-03) → `monById.get(slug)` → `pointFor(m)` = `${coords.lat},${coords.lng}`. **NO type filter** (Pitfall 2 — Saturday MUST include vaticano `guided` + auditorium `concert`). | RESEARCH §Pitfall 2 |
| Reactivity | `:href` + `v-if` computed at SSG prerender. NO imperative DOM mutation, NO `appendChild`, NO re-init. (Replaces the original's `stats.appendChild(btn)`.) | RESEARCH §Pattern 2 |
| Hover affordance | `filter: brightness(1.08); transform: translateY(-1px)` — verbatim, CSS-only. | `base.css:411` |
| Mobile | Under 600px: `width:100%`, centered, `margin-left:0`. | `base.css:413` |
