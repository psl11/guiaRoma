## Contrato de esquema (RESEARCH Pattern 1, sonda zod verificada)

- Las 5 filas actuales (`stop`, `transport`, `meta`, `food`, `reservation`) se MUEVEN sin cambiar a constantes (`StopRow`, `TransportRow`, `MetaRow`, `FoodRow`, `ReservationRow`) y a una tupla `BASE_ROWS`.
- `export const BaseTimelineRow = z.discriminatedUnion('kind', [...BASE_ROWS])` — filas permitidas dentro de una opción (sin `choice`: un solo nivel por construcción).
- `export const ChoiceOption = z.strictObject({ label: z.string().min(1), title: Md.min(1), rows: z.array(BaseTimelineRow).min(1) })`.
- `export const ChoiceRow = z.strictObject({ kind: z.literal('choice'), heading: Md.min(1).optional(), options: z.array(ChoiceOption).min(2).max(3) })`.
- `export const TimelineRow = z.discriminatedUnion('kind', [...BASE_ROWS, ChoiceRow])`; tipos `export type BaseTimelineRow` y `export type ChoiceRow` (z.infer).
- NUNCA `z.lazy` ni recursión: Content solo crea columnas de las propiedades de primer nivel (`timeline` es una columna JSON) y un `toJSONSchema` que lance deja la colección sin columnas.
