<objective>
Construir el harness de fidelidad 1:1 (D-07/D-08): un script cheerio que extrae del index.html, por id de ficha, el texto visible y el conjunto de enlaces (href externos de Maps + anclas internas a id), lo normaliza y lo compara contra los datos YAML migrados; mas el spec Vitest que ejecuta ese diff y FALLA si falta o sobra texto o algun enlace. Esta es la red automatica contra regresiones de transcripcion (DATA-04), independiente del golden visual (Fase 8) y de la revision manual.

Este plan es independiente del contenido de los YAML: parsea index.html (solo-lectura) y compara contra lo que exista. Depende del Plan 01 unicamente porque cheerio se instala alli. Mientras Wave 2 migra, el spec puede ejecutarse de forma incremental por id ya migrado.

Purpose: La transcripcion manual de ~64 fichas densas con muchos enlaces internos es propensa a perder un href o cambiar texto (Pitfall 4). Sin el diff automatico, DATA-04 dependeria de revision a ojo.
Output: scripts/migration-diff.ts (extraccion + normalizador + diff, opcional bootstrap), tests/data/migration-diff.spec.ts (puerta).
</objective>
