Run the gate ONCE, classify every visual diff (D-02), drive pnpm verify to GREEN (SC#4), and record the classification. This is the empirical heart of F8: the first time the generated Nuxt site is compared pixel-for-pixel against the frozen golden.

Per D-02: run the visual-diff once; for each diff, decide real vs demonstrable-non-deterministic-artifact. REAL diffs (structure/color/spacing/typography out of square) -> fix the Nuxt component until the view passes within maxDiffPixelRatio 0.01 (paridad = ley; the component is wrong, not the baseline). ARTIFACT diffs (provably non-deterministic) -> justify a narrow threshold/mask IN WRITING with the evidence. Do NOT pre-apply a font mask — RESEARCH disk-verified the fonts are glyph-equivalent (24-byte sfnt delta; byte-identical latin unicode-range), so inspect the first run's *-diff.png first; a font-AA mask is only warranted if a text-heavy view fails ONLY on faint subset-boundary noise, and even then it is documented.

Purpose: green pnpm verify is the 1.0 precondition (SC#4) and the objective proof of SC#1+SC#2+SC#3. The 56 frozen PNGs are NEVER rebaselined (D-01). Plan 07 closes with the human sign-offs.
Output: .planning/phases/08-verificaci-n-de-paridad/diff-classification.md + (only if real diffs surface) minimal component fixes. No new dependencies.
