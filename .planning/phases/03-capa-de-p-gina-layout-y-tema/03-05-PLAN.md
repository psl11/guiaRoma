| Boundary | Description |
|----------|-------------|
| URL route param (slug) → dynamic trips route | The slug param reaches useTrip and a 404 guard; it selects a content key (parameterized .where), never a query string or DOM sink. |
| browser localStorage (roma-theme) → generated head script | The color-mode inline script reads roma-theme and sets the data-theme attribute before paint. Value space is light/dark. |
| static SSG output → public | The whole 1.0 is a static, no-server, no-auth, no-input site; / is the only prerendered page. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Tampering | dynamic trips route slug param | accept | Unknown slug → createError 404 (RESEARCH §Security Domain); .where is parameterized; no SSRF/path risk since /trips/* is never prerendered and the param only selects a collection key. |
| T-03-08 | Tampering | localStorage roma-theme → data-theme attribute | accept | The module-provided script normalizes the stored value to a known mode and only sets the data-theme attribute (no HTML injection sink). Constrained to light/dark. |
| T-03-09 | Information Disclosure | prerender scope | mitigate | D-01 keeps prerender.routes to a single / entry and forbids /trips/* links; Task 2 asserts the build emits no trips directory, preventing accidental duplicate-content exposure. |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No package install in this plan (RESEARCH §Package Legitimacy Audit: F3 installs nothing). Playwright + Nuxt + color-mode are already installed/vetted. No [ASSUMED]/[SUS] package. |

**Conclusion:** No high-severity threats; no blocking mitigations required. Static SSG with no server/auth/input; the only param is a slug guarded by a 404; theme state is a constrained 2-value preference with no injection sink.
