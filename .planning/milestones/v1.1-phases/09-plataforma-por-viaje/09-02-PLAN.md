## Reglas de `checkTrip` (contrato — RESEARCH §Pattern 5, D-05/D-10/D-11)

| rule | Comprueba | Mensaje (siempre con `file`) |
|------|-----------|------------------------------|
| `yaml-parse` | el YAML parsea (el loader captura la excepción de `yaml`) | `YAML inválido: <primera línea del error>` |
| `yaml-object` | el YAML parseado es un objeto plano (no null, no array, no escalar) | `el YAML no es un objeto (vacío, lista o escalar)` |
| `trip-yml` | existe `trip.yml` en la carpeta (file = `<base>/trip.yml`) | `falta trip.yml en la carpeta del viaje` |
| `trip-slug` | `trip.yml.slug` cumple `TRIP_SLUG_RE` **y** es igual a la carpeta | `slug "x" no cumple ^[a-z0-9]+$ (D-05)` / `slug "x" ≠ carpeta "y"` |
| `trip-field` | en todo fichero que no es `trip.yml`, `data.trip` == carpeta (`trip.yml` no tiene campo `trip`) | `trip "x" ≠ carpeta "y"` |
| `stray-file` | todo `.yml`/`.yaml` casa con un patrón de `COLLECTIONS` (Content ignora el resto sin avisar) | `fichero fuera de las colecciones (Content lo ignoraría)` |
| `reserved-key` | claves de NIVEL SUPERIOR ∩ `RESERVED_KEYS` = ∅ (el `meta` anidado de `TransportMode` es legítimo) | `campo reservado de Content "meta"` |
| `unknown-key` | claves de nivel superior ⊆ `Object.keys(row.shape)` de su colección (zod las tiraría sin avisar) | `campo desconocido "x"` |
| `basename-slug` | slug no vacío y `basename(fichero, '.yml')` == slug (excepto `trip.yml`) | `fichero sin slug` / `basename "a" ≠ slug "b"` |
| `dup-id` | slugs únicos entre day/monument/food/artist/reference del viaje | `id "x" duplicado en <ficheros>` |
| `fixed-anchor` | slugs de day/monument/food/artist ∉ `FIXED_DOM_IDS` y sin prefijo `note-` (`reference` exento: `reservas`/`practica` son el singleton de su sección) | `id "mapa" choca con un ancla fija de TripView` |
| `ref` | las 6 referencias estructuradas actuales resueltas DENTRO del viaje (day.cards→monument; timeline stop/food→monument∪food; monument.artists→artist kind artist; monument.arch→artist kind arquitectura; artist.seenIn→monument; reservas.table.ref→monument∪food) | mensajes actuales de invariants.spec.ts |
| `anchor` | cada `[t](#x)` de cualquier string de cualquier fichero (incl. `trip.yml`) resuelve a un slug no-trip del MISMO viaje o a `SECTION_ANCHORS` | `ancla #x no existe en el viaje "y"` |
| `cross-trip-link` | ningún destino de enlace Markdown contiene `/trips/` ni empieza por `trips/` | `enlace entre viajes no admitido (D-11)` |

`SECTION_ANCHORS` = inicio, mapa, reservas, gastronomia, practica, arte, arquitectura (TripView.vue:84-196, TheHero.vue:57). `CHROME_IDS` = leaflet-map, map-offline-banner, light-toggle, resumen-toggle, back-btn, search, search-results, nav-pills. `RESERVED_KEYS` = id, meta, stem, extension, __hash__ (`metaStandardSchema` de @nuxt/content 3.14.0 + columna `__hash__`). Los días `viernes…martes` NO van en la lista fija (son slugs de datos; `dup-id` los cubre).
