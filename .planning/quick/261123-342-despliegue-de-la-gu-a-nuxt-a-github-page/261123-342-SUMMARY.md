## Deviations from Plan

**1. [Expectation mismatch, not fixed: needs a user decision] The deploy did not fail and the old guide is no longer served**
- **Expected:** the deploy-pages job fails until psl11 switches Pages Source to "GitHub Actions", and the old single-file guide stays live.
- **Actual:** deploy-pages succeeded while the source is still legacy, and the Nuxt guide replaced the old guide on the live URL.
- **Consequence: a race on every push to main.** Both the legacy Jekyll build and this workflow deploy each push, and the one that finishes last wins. The legacy build usually finishes first (about 40 s against about 75 s), so the Nuxt site normally ends up live, but GitHub does not guarantee that. If the Actions gate fails, the legacy build serves the old guide, which acts as a fallback.
- **docs/DEPLOY.md is now partly inaccurate:**
  - «Mientras no se active» says the deploy fails and the old guide stays live. Neither is true.
  - Step 3 of «Activarlo» says /trips/roma/ "hoy devuelve 404". It now returns 200.
  - I did not correct it, because any change has to reach main and that push would trigger another racing deploy.
- **What psl11 should do:** switch Settings, Pages, Source to "GitHub Actions". That removes the race and makes the Nuxt deploy the only one.
- **If the old guide should stay live until a later decision:** go back to the legacy deploy, for example by re-running run 45141890284 or disabling the workflow ("Disable workflow"). I did not revert anything on main.
